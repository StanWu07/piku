# Piku · 日常助手

一个以本地数据为主的 macOS 桌面助手。手动记录或粘贴消息，使用 ChatGPT 账号通过官方 Codex App Server 分析待办，并在逐次授权后执行具体动作。0.2 版仅支持 ChatGPT 登录，已移除 API Key 接入。

## 启动

开发启动需要 Node.js 22 或更新版本。电脑还需安装官方 ChatGPT / Codex 桌面版（包含 Codex 运行组件），或安装官方 Codex CLI。本机已检测到可用的 Codex 0.153.4。

使用打包后的应用时不需要运行下面的终端命令。更新后请先用 Cmd+Q 退出旧版，再双击 `release/mac-arm64/Piku.app`。

```sh
npm install
npm start
```

打包桌面应用：`npm run pack`。生成的应用位于 `release/mac-arm64/Piku.app`（Apple Silicon）或 `release/mac/Piku.app`（Intel）。`npm run dist` 可生成 DMG。当前为本地开发版本，采用临时签名，不使用你的开发者证书，未做 Apple 公证。

## 使用

1. 打开“助手设置”，点击“使用 ChatGPT 登录”。Piku 会打开官方浏览器登录页，由你完成账号登录；返回后账号状态自动更新。可点击“取消登录”或“刷新连接”。模型列表从账号读取，默认自动选择账号默认模型。使用账号对应的 Codex 权益与额度，可用性取决于套餐及账号权限。
2. 点击“记下一件事”，添加任务、截止时间和可选提醒时间。也可点击“粘贴消息”，让 GPT 提取后勾选导入。
3. 点击“分析我的待办”，查看优先级建议和下一步。分析只给建议，不直接更改任务优先级或完成状态。
4. 到“授权中心”查看动作的全部内容，再点击“授权并执行”。支持把完整文稿保存为本地 Markdown、打开任务中明确提供的 HTTP/HTTPS 网页、设置或替换任务提醒。执行文稿后可在 Finder 查看。
5. 提醒由主进程每 15 秒检查，关闭窗口后继续在菜单栏运行。真正退出应用或关机时不会提醒；启动及电脑唤醒后补提醒。可在设置中测试系统通知。请允许系统通知，勿扰模式可能隐藏横幅。
6. 可选开启每小时后台分析：会将未完成待办发送至 OpenAI 并使用账号的 Codex 额度，只生成建议。首次开启将在下一轮后台检查时分析。新建议产生时才通知；失败后至少间隔一小时重试。退出登录会关闭自动分析，普通任务提醒仍可使用。

目前任务来源为手动输入和粘贴消息，未连接微信、QQ、邮箱或系统日历；不会发送消息、付款、购买、删除用户文件，也不会执行任意终端命令。打开网页、生成草稿不代表原任务已完成，仍需用户确认完成。

## 数据与授权

- 待办、分析、建议和最近 300 条活动记录保存在 Electron `userData` 目录，macOS 通常为 `~/Library/Application Support/Piku/`；任务数据本身为本地 JSON，非加密数据库。
- 登录使用官方 `account/login/start` 浏览器 OAuth 流程。账号密码只在官方页面输入；登录凭据由 Codex 管理，使用系统钥匙串保存，Piku 不读取或向界面暴露 token。
- Codex 子进程使用独立的配置及登录目录 `userData/chatgpt`，不会读取、复制或退出你其他 Codex 应用的登录状态。只继承运行所需的有限环境变量，不继承 API 凭据。
- 移除了直接 Responses API 请求、API Key 设置和环境变量接入路径；升级时会删除旧版的 `credential.bin`，保留任务、建议和活动记录，模型重置为账号默认，后台分析默认关闭，需用户重新开启。
- 分析通过本机 Codex App Server 的 stdio JSON-RPC 运行，使用临时会话和 JSON Schema 输出。临时会话不等于服务端零保留政策，数据处理遵循 ChatGPT / Codex 对应的账号政策。
- 分析会话禁用环境访问、shell、应用、插件、hooks 和网页搜索，设置只读沙箱，并拒绝所有服务端工具执行及权限请求。生成结果经原有动作白名单校验后交给用户授权。
- 手动分析会发送未完成任务，提取会发送粘贴文本。开启定时分析需要在设置中明确勾选。
- 执行动作有固定白名单，无通用 shell。用户授权的是不可变的具体提案；修改或完成关联任务会取消待授权旧提案。执行前重新校验，在调用系统接口前落盘执行中状态，拒绝重复授权。
- 中断中的执行在重启后标记为“需核实结果”，不自动重试，避免产生重复副作用。
- 关闭窗口隐藏到菜单栏；在菜单栏选择“退出 Piku”或按 Cmd+Q 才会退出。

## 验证

```sh
npm test
npm run test:desktop
```

核心测试覆盖持久化、提醒筛选、授权与重复执行防护、账号迁移、官方登录 URL 校验、登录取消与超时、退出、额度错误、进程退出、请求关联和结构化结果。桌面测试启动真实 Electron 窗口，以临时目录和模拟账号响应验证登录、取消、退出、模型列表、任务操作及文稿授权。截图位于 `test-output/`，其中任务和账号均为测试样例。真实 Codex 初始化、账号读取、会话配置和登录启动/取消流程已验证；真实模型分析仍需用户完成登录后验证。正常启动不使用模拟账号或模拟分析。

实现参考：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[ChatGPT / Codex 登录说明](https://learn.chatgpt.com/docs/auth)、[Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)。
