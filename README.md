# Piku · 日常助手

一个以本地数据为主的 macOS 桌面助手。点击悬浮图标框选截图，也可手动记录或粘贴消息，使用 ChatGPT 账号通过官方 Codex App Server 分析待办，并在逐次授权后执行具体动作。0.3.7 版默认显示精简待办清单，并保留悬浮快速记录入口，仅支持 ChatGPT 登录，无需 API Key。

## 启动

开发启动需要 Node.js 22 或更新版本。电脑还需安装官方 ChatGPT / Codex 桌面版（包含 Codex 运行组件），或安装官方 Codex CLI。本机已检测到可用的 Codex 0.153.4。

使用打包后的应用时不需要运行下面的终端命令。更新后请先用 Cmd+Q 退出旧版，再双击 `release/mac-arm64/Piku.app`。

```sh
npm install
npm start
```

打包桌面应用：`npm run pack`。生成的应用位于 `release/mac-arm64/Piku.app`（Apple Silicon）或 `release/mac/Piku.app`（Intel）。`npm run dist` 可生成 DMG。当前为本机自用开发版本，固定使用本机 Apple Development 证书签名，未做 Apple 公证。签名证书指纹固定在 package.json，开启 forceCodeSigning；缺少该证书时打包失败，不回退到临时签名。私钥只留在系统钥匙串，不进入仓库。本机开发签名设置 timestamp 为 none，不依赖在线时间戳服务；这不是已公证的分发构建，证书到期后需重新签名。首次从临时签名切换后需重新授权屏幕录制；后续保留同一证书和应用标识，更新应保持相同的代码身份。证书到期或更换时需重新核验身份和系统授权。正式对外分发应另行配置 Developer ID Application 签名和公证。

## 截图记事

启动后显示小尺寸待办清单和可拖动的悬浮图标。主页直接列出未完成事项，可切换已完成或搜索；设置在顶栏，助手建议、粘贴消息和活动记录收在“更多”中。右键图标可打开待办清单；菜单栏可以恢复隐藏的图标。

1. 首次使用，右键打开待办清单，在“助手设置”完成 ChatGPT 登录。
2. 点击悬浮图标，弹出仅含截图按钮和输入框的小栏。直接输入一句话，回车保存普通待办；点击其他位置或按 Esc 收起，未提交的文字保留。点击左侧截图按钮后，拖动鼠标框选需要记录的内容；按 Esc 取消。
3. 每次框选后 GPT 将整张截图整理成一条待办，不拆成多条；只提取尚需完成的事情：标题简短概括要做什么，“具体内容”仅保留必要要求和明确期限，略去闲聊、通知背景和无关信息。可以修改标题、内容或统一截止时间，再点击确认保存。取消或关掉小窗不会保存。
4. 没有截止时间就是普通待办；有截止时间也不会自动设置提醒。识别失败时可以重试或“自己写一句”。

首次截图时 macOS 可能要求允许屏幕录制，请在系统设置中为 Piku 开启权限并重新打开应用。仅选中的区域会发送给 GPT；本地临时图片在确认、取消或正常退出后删除，待办只保留文字。识别使用账号额度，需要支持图片的模型。截图过程中 Piku 窗口会暂时隐藏。

## 先判断，再确认执行

记录、修改或查看待办都不会自动进行分工判断。在事项详情中点击“判断助手能否执行”后，才分析这一条待办；未登录时先登录，再回来点击。每次判断会发送该事项的标题、说明和时间至 OpenAI，并使用账号额度。

- 助手可完成：当前能力足以完成这件事，例如根据已有材料生成完整文稿。
- 助手可协助：能准备具体部分，但仍需你发送、提交或进行实际操作。
- 需要你完成：需要线下处理、个人练习，或缺少执行条件。详情会说明原因和你需要做的部分。

点击待办，再点击“判断助手能否执行”查看分工。可执行动作先点“查看并确认”，检查完整文稿、网页或提醒时间，再选择“授权并执行”或拒绝。判断本身不会调用系统执行接口，也不会把事项标为完成。执行仍限于保存本地 Markdown、打开事项明确提供的网页、设置提醒；不包含自动发送、购买、预约或任意操作电脑。修改事项会使旧判断和待授权动作失效；失败可在详情中重试。

## 其他使用方式

1. 打开“助手设置”，点击“使用 ChatGPT 登录”。Piku 会打开官方浏览器登录页，由你完成账号登录；返回后账号状态自动更新。可点击“取消登录”或“刷新连接”。模型列表从账号读取，默认自动选择账号默认模型。使用账号对应的 Codex 权益与额度，可用性取决于套餐及账号权限。
2. 点击“记下一件事”，输入一句话后按回车即可保存，不需要选择分类、优先级或提醒时间。有期限时展开“截止时间（选填）”，只记录截止时间，不自动创建提醒；没有期限就作为普通待办。点击已有任务先查看完整标题、具体内容和截止时间，可直接标记完成；需要修改时点击“编辑”。也可点击“粘贴消息”，让 GPT 提取后勾选导入。
3. 点击“分析我的待办”，查看优先级建议和下一步。分析只给建议，不直接更改任务优先级或完成状态。
4. 到“授权中心”查看动作的全部内容，再点击“授权并执行”。支持把完整文稿保存为本地 Markdown、打开任务中明确提供的 HTTP/HTTPS 网页、设置或替换任务提醒。执行文稿后可在 Finder 查看。
5. 提醒由主进程每 15 秒检查，关闭窗口后继续在菜单栏运行。真正退出应用或关机时不会提醒；启动及电脑唤醒后补提醒。可在设置中测试系统通知。请允许系统通知，勿扰模式可能隐藏横幅。
6. 可选开启每小时后台分析：会将未完成待办发送至 OpenAI 并使用账号的 Codex 额度，只生成建议。首次开启将在下一轮后台检查时分析。新建议产生时才通知；失败后至少间隔一小时重试。退出登录会关闭自动分析，普通任务提醒仍可使用。

目前任务来源为框选截图、手动输入和粘贴消息，未连接微信、QQ、邮箱或系统日历；不会发送消息、付款、购买、删除用户文件，也不会执行任意终端命令。打开网页、生成草稿不代表原任务已完成，仍需用户确认完成。

## 数据与授权

- 待办、分析、建议和最近 300 条活动记录保存在 Electron `userData` 目录，macOS 通常为 `~/Library/Application Support/Piku/`；任务数据本身为本地 JSON，非加密数据库。
- 登录使用官方 `account/login/start` 浏览器 OAuth 流程。账号密码只在官方页面输入；登录凭据由 Codex 管理，使用系统钥匙串保存，Piku 不读取或向界面暴露 token。
- Codex 子进程使用独立的配置及登录目录 `userData/chatgpt`，不会读取、复制或退出你其他 Codex 应用的登录状态。只继承运行所需的有限环境变量，不继承 API 凭据。
- 移除了直接 Responses API 请求、API Key 设置和环境变量接入路径；升级时会删除旧版的 `credential.bin`，保留任务、建议和活动记录，模型重置为账号默认，后台分析默认关闭，需用户重新开启。
- 分析通过本机 Codex App Server 的 stdio JSON-RPC 运行，使用临时会话和 JSON Schema 输出。临时会话不等于服务端零保留政策，数据处理遵循 ChatGPT / Codex 对应的账号政策。
- 分析会话禁用环境访问、shell、应用、插件、hooks 和网页搜索，设置只读沙箱，并拒绝所有服务端工具执行及权限请求。生成结果经原有动作白名单校验后交给用户授权。
- 手动分析会发送未完成任务，提取会发送粘贴文本，截图识别会发送选中的区域。开启定时分析需要在设置中明确勾选。
- 执行动作有固定白名单，无通用 shell。用户授权的是不可变的具体提案；修改或完成关联任务会取消待授权旧提案。执行前重新校验，在调用系统接口前落盘执行中状态，拒绝重复授权。
- 中断中的执行在重启后标记为“需核实结果”，不自动重试，避免产生重复副作用。
- 关闭窗口隐藏到菜单栏；在菜单栏选择“退出 Piku”或按 Cmd+Q 才会退出。

## 验证

```sh
npm test
npm run test:desktop
```

核心测试覆盖持久化、提醒筛选、授权与重复执行防护、账号迁移、官方登录 URL 校验、登录取消与超时、退出、额度错误、进程退出、请求关联和结构化结果。桌面测试启动真实 Electron 窗口，以临时目录和模拟账号响应验证登录、取消、退出、模型列表、任务操作及文稿授权。截图位于 `test-output/`，其中任务和账号均为测试样例。真实 Codex 初始化、账号读取、会话配置和登录启动/取消流程已验证；真实模型分析仍需用户完成登录后验证。截图测试另覆盖区域截图命令、取消与清理、识别中止、确认前不保存、编辑后保存和关闭取消；桌面流程使用测试图片与模拟 GPT 响应，不截取实际桌面。真实系统框选及 GPT 图片识别仍需在授权屏幕录制并登录后验证。正常启动不使用模拟账号或模拟分析。

实现参考：[Codex App Server](https://learn.chatgpt.com/docs/app-server)、[ChatGPT / Codex 登录说明](https://learn.chatgpt.com/docs/auth)、[Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)。
